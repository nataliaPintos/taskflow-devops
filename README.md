# TaskFlow DevOps

Projeto desenvolvido para a disciplina **DevOps na Prática**, do curso de **Análise e Desenvolvimento de Sistemas (ADS) da PUCRS**.

O objetivo do projeto é aplicar na prática conceitos de:

- Integração Contínua (CI)
- Testes automatizados
- Git e GitHub
- GitHub Actions
- Infraestrutura como Código (IaC)
- Terraform
- AWS

## Tecnologias utilizadas

- React
- TypeScript
- Vite
- Vitest
- GitHub Actions
- Terraform
- AWS

## Como executar

Instale as dependências:

npm install

Execute a aplicação:

npm run dev

Execute os testes:

npm run test

## Infraestrutura

Os scripts de Infraestrutura como Código estão na pasta `infrastructure` e utilizam Terraform para provisionamento de recursos na AWS.
